🌐 Universal Selector (*) Demo

The universal selector has NO specificity (0). Any other selector beats it.

This heading is targeted by:

  • Universal selector: * { color: purple; }
  • Type selector: h3 { color: teal; }

The teal color wins because type selector (specificity 1) beats universal (specificity 0).

📊 Specificity Reference

Selector Type Example Specificity Value
Universal * 0
Type/Element div, p, h1 1
Class .class 10
ID #id 100
Inline style style="color: red;" 1000
!important color: red !important; ∞ (wins everything)

Specificity Calculation Examples:

  • #header = 100
  • .nav .link = 20 (10 + 10)
  • div p a = 3 (1 + 1 + 1)
  • #header .nav a = 111 (100 + 10 + 1)
  • .container .content p = 21 (10 + 10 + 1)
