CSS Cascade & Specificity Demo

Which styles apply?

This box has:

  • Class "cascade-box" (styled in internal <style> tag)
  • Inline style: background-color: #ffe6f0

Result: The inline style wins for background-color, but the border from internal CSS still applies!

Specificity Hierarchy

Selector Type Example Specificity Value
Universal * 0
Type/Element div, p, h1 1
Class/Pseudo-class .class, :hover 10
ID #id 100
Inline style style=" " 1000
!important property: value !important ∞ (wins everything)
